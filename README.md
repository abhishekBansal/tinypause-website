# TinyPause Website

Official marketing landing page for [TinyPause](https://tinypause.anvik.studio) — the mindful browser extension for intentional browsing, built by [anvik.studio](https://anvik.studio).

## Features

- Modern single-page landing site with Tailwind CSS & Plus Jakarta Sans / Fraunces typography
- Interactive in-browser TinyPause simulator widget
- Comprehensive feature breakdowns, architecture notes, and FAQ
- Optimized for mobile and desktop screens

## Deployment

Hosted on GitHub Pages at [tinypause.anvik.studio](https://tinypause.anvik.studio).
